空飛ぶクルマデザインアプリ PWA導入手順

【あと1ファイル必要です】
A-Frame 1.7.0を以下のURLからMacでダウンロードしてください。
https://aframe.io/releases/1.7.0/aframe.min.js
保存したファイル名を aframe.min.js にして、vendor フォルダに配置してください。
※今回のZIPにはA-Frameが含まれません。配置前は3D表示・完全オフライン動作ができません。

【公開】
フォルダ構造を維持してGitHub PagesなどのHTTPSサイトへアップロード。
iPadのSafariで公開URLを開き、3Dモデルが表示されることを確認。
Safariの共有メニューから「ホーム画面に追加」。
オンラインで初回起動後、Wi-Fiを切って起動・塗り絵・3D表示を確認。

【印刷】
4×6インチ横向き、4機分のレイアウトは元HTMLから維持しています。
Canon TS7630とWi-Fi接続して印刷してください。

【注意】
オフライン保存が完了したかを確認するには、オフライン状態でアプリを再起動してください。
公開後の更新時はsw.jsのCACHE名を変更して再公開してください。
